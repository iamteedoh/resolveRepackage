Initial public release. Adopts the Teedoh Labs OSS repo standard: CI (lint/build + gitleaks secret scan + community & licensing checks), release automation, GPLv3 licensing, and community health files.

All notable changes to resolveRepackage are documented here.

This project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
Release entries are maintained by release-please from Conventional Commit PR
titles merged into `main`.

There are no tagged releases yet. The first releasable `feat:` or `fix:` change
will prepare the initial source release.
